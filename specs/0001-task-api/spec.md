## 1. Roles

| Role | Granted by | Notes |
|---|---|---|
| `Member` | Registration (default) | |
| `Admin` | Seeded admin, or promoted by an admin | |

## 2. Authorization policies

| Policy | Rule |
|---|---|
| `AuthenticatedUser` | Any valid JWT (the fallback policy: every endpoint requires it unless marked anonymous) |
| `AdminOnly` | Role claim is `Admin` |
| `TaskOwnerOrAdmin` | Resource-based: the task's `OwnerId` equals the caller's id, or the caller is `Admin` |

## 3. Endpoints

| Method | Route | Auth | Success | Errors |
|---|---|---|---|---|
| POST | `/auth/register` | Anonymous | `201` user | `400` invalid, `409` email taken |
| POST | `/auth/login` | Anonymous | `200` `{ accessToken, expiresAt }` | `401` bad credentials |
| GET | `/auth/me` | Authenticated | `200` `{ id, email, role }` | `401` |
| GET | `/categories` | Authenticated | `200` list | `401` |
| POST | `/categories` | `AdminOnly` | `201` category | `400`, `403`, `409` duplicate name |
| DELETE | `/categories/{id}` | `AdminOnly` | `204` | `403`, `404` |
| GET | `/tasks` | Authenticated | `200` own tasks (Admin: all) | `401` |
| GET | `/tasks/{id}` | `TaskOwnerOrAdmin` | `200` | `404` (also when not owner) |
| POST | `/tasks` | Authenticated | `201` task | `400` invalid title or unknown category |
| PUT | `/tasks/{id}` | `TaskOwnerOrAdmin` | `200` | `400`, `404` |
| DELETE | `/tasks/{id}` | `TaskOwnerOrAdmin` | `204` | `404` |
| GET | `/admin/users` | `AdminOnly` | `200` list (no password hashes) | `403` |
| PUT | `/admin/users/{id}/role` | `AdminOnly` | `200` | `400` unknown role, `403`, `404` |

## 4. Validation rules

- Email: required, contains `@`, max 256 chars, stored lower-case.
- Password: min 8 chars. Stored with ASP.NET Core `PasswordHasher` (PBKDF2), never logged or returned.
- Task title: required, 1 to 200 chars. Category name: required, 1 to 50 chars, unique.
- Errors are RFC 9457 `ProblemDetails` / `ValidationProblem` responses.

## 5. Security requirements (from the `api-security` skill)

- S1. JWT signing key comes from configuration; startup fails if it is missing or shorter than 32 bytes.
- S2. Tokens validate issuer, audience, lifetime and signing key. Lifetime 60 minutes.
- S3. Login returns the same `401` for unknown email and wrong password.
- S4. Non-owners get `404`, not `403`, on task endpoints.
- S5. Responses never include `PasswordHash`.

## 6. Out of scope

Refresh tokens, email confirmation, rate limiting, pagination.

## 7. Acceptance

Every row in section 3 and every rule S1 to S5 has at least one test in `tests/TaskApi.Tests`.
